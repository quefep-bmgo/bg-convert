# bg-convert

A Python tool for converting Blockman GO maps to Minecraft Java worlds and back.

I am starting with the conversion paths I can test on real maps. The version range
is not settled yet. See the open issues for the current plan.

## What is here

Not much yet. The repo has the package layout and the command entry point.

## Development

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -e ".[dev]"
python -m pytest
```
